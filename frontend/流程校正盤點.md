# 彰化縣癌症篩檢活動預約系統：第一階段盤點

盤點日期：2026-10-05。此專案目前是 Vue 3／Pinia／Vite 的本機 DEMO；Laravel API 僅有 `/api` 歡迎訊息及受 Sanctum 保護的 `/api/user`，前端未呼叫業務 API。

## 現有結構

- Route：`/` 前台首頁、`/booking` 預約、`/screening-guide` 篩檢須知、`/contact` 聯絡資訊、`/account` 登入及申請、`/admin` 後台（以 `section` query 切換工作區）、`/bowel-scan` 條碼掃描。
- Page／view：`IndexView`、`PublicHomeView`、`PublicBookingView`、`PublicInformationView`、`AccountView`、`AdminDashboardView`、`AdminWorkView`、`BowelScanView`。
- 共用 component：`PublicBrand`、`PublicNavigation`、`PublicFooter`、`PublicIcon`、`ScreeningGuide`、`AdminSampleData`、`BowelBarcode`、`BowelLabel`、`BowelTubeWorkstation`。
- 資料：`stores/demo.js` 存帳號、活動、預約、領管院所、醫療設定與糞管追蹤；`demoInvitations.js`、`demoEligibility.js`、`adminTasks.js`、`bowelLabels.js`、`tubeOperations.js` 提供本機規則及模擬名冊。條碼比對名冊另用 localStorage。
- 權限：帳號申請僅提供一般使用者、單位管理者，並檢查同機構不得有第二位單位管理者；後台可直接開啟，查詢範圍以固定彰化市模擬。
- 預約：邀約碼帶入資料；一般預約原先先選項目再驗證資格；設站可搜尋鄉鎮／日期與時段；腸篩可選衛生所／藥局領管；手機及選填 E-mail 以畫面顯示模擬 OTP；子抹可加選其他項目。
- 腸篩／糞管：院所每週多時段與公休日曆；名單、標籤列印及取消、CSV、掃碼比對、批次或逐筆繳管、10 分鐘內復原。生命週期目前可在名單動態用「下一狀態」逐級推進。

## 【目前已符合】

- 前後台共用既有導覽及 RWD；邀約碼 10 碼驗證和名冊帶入；基本資料、現居地址及同戶籍地址；設站搜尋與額滿時段 disabled；腸篩領管院所名稱、地址、時間；三種後台業務入口；整篩時段總名額及對外名額；設站合作院所與子抹車設定；腸篩每日多時段及公休日曆；標籤全選／單選、列印、取消列印、CSV；繳管批次、查詢與掃碼；帳號申請步驟及第二位單位管理者檢查。

## 【部分符合】

- 資格及邀約碼只查本機模擬資料；手機／E-mail OTP 顯示在頁面；預約及權限沒有後端保存或保護；Excel 匯出實際為 Excel 可讀的 CSV；合作院所與活動公布缺少正式資料與審核；標籤列印使用瀏覽器視窗，未連標籤機。
- 加選其他篩檢已有一次驗證及共同確認，但提示主要出現在基本資料之前；需在基本資料後再次確認資格。

## 【缺少】

- 真實名冊、資格、邀約碼、OTP、通知、醫事機構及戶政介接；伺服器端 RBAC 與機構資料範圍；逾期 7／14 天自動追蹤；正式 Excel `.xlsx`；跨裝置同步與交易式名額控管。

## 【流程衝突】

- 一般預約原先先選項目、再輸入身分證，且沒有出生年月日欄位；甲方流程要求先以身分證及出生年月日查詢，再顯示符合的項目。
- 糞便潛血原先可選設站檢查時段；甲方流程要求預約領取採檢管。
- 名單動態的「下一狀態」可直接將已預約推進到已派送；甲方要求由標籤列印觸發，並由實際接收、領取、繳管、送驗動作觸發後續狀態。
- 公休日曆只能操作本月起三個月；需求要求可設定未來月份。

## 【建議保留但需要調整：優化流程】

- 保留「查詢／取消預約」、多項篩檢同批檢查與原子建立、額滿時段 disabled、手機掃碼比對、繳管後 10 分鐘內復原、模擬測試資料入口。這些改善操作效率或防止錯誤；調整位置與狀態條件，不移除功能。
