# 彰化縣癌症篩檢活動預約系統 DEMO

本機展示版使用專案原有的 Vue 3、Vue Router、Pinia、Vite，並加入 Tailwind CSS。依據工作資料夾內的 Word 需求，先呈現活動場次管理與民眾預約的主要流程。

## 啟動

在 `frontend` 目錄執行：

```sh
npm install
npm run dev
```

瀏覽終端機顯示的本機網址，通常為 `http://localhost:5173/`。可執行 `npm run build` 檢查編譯。

- 民眾前台：`http://localhost:5173/`
- 管理後台：`http://localhost:5173/admin`
- 帳號登入與申請：`http://localhost:5173/account`
- 民眾完整預約流程：`http://localhost:5173/booking`
- 篩檢須知：`http://localhost:5173/screening-guide`
- 聯絡我們：`http://localhost:5173/contact`

前台右上角可進入「後台登入／帳號申請」；登入頁提供測試帳號。後台右上角可返回前台。這是 DEMO 畫面切換，直接輸入後台網址仍可進入，尚未加入真正的登入與權限管制。

## 目前可操作

- 工作首頁：預約查詢與名單入口；腸篩管理另有五個階段的待辦圖表。
- 民眾端：整篩邀約碼、設站資格確認、腸篩領管院所、場次與時段、手機及 E-mail 驗證、基本資料、預約完成、查詢及取消。
- 活動場次：查詢、新增、聯絡與提醒設定、檢視、總名額及逐時段名額設定、匯出 CSV。
- 醫療院所：子抹／乳攝配合院所、子抹車、腸篩院所營業時間與公休日曆。
- 名單處理：後台輸入三類預約、依身分證查詢修改及取消、預約清冊篩選與匯出。
- 腸篩作業：檢體管狀態更新、標籤列印視窗、批次繳管與清冊匯出。
- 帳號申請：一般登入、手機驗證、E-mail 驗證、帳密設定、基本資料、忘記密碼、重新設定密碼的本機操作示範。

一般預約及設定資料只存在目前瀏覽器頁面的記憶體，重新整理後會重設；腸篩條碼名冊另存於此瀏覽器的 localStorage，讓重印、掃描及重新整理後能比對同一編號。本版沒有資料庫、後端 API、真實登入驗證、簡訊與電子郵件發送，也沒有雲端服務。匯出使用可由 Excel 開啟的 UTF-8 CSV，並非 `.xlsx`；腸篩跨裝置比對名冊另提供 JSON。細節差距請見 [需求對照.md](需求對照.md)。

## 腸篩長方形條碼與掃描測試

### 腸篩管理版面與繳管

- 參考提供的圖片配置，保留原有「腸篩管理、繳管作業、名單動態、標籤列印、院所與公休」名稱及既有欄位用語。待辦數字使用目前名冊的五個既有階段，不套用圖片的數字、單位或警告文字。
- 腸篩各頁共用上方待辦數字及下方操作頁籤。「待辦總覽」頁籤與大型圖表已移除，僅保留上方五項待辦資訊，點「腸篩管理」先進入繳管作業。每項待辦可開啟對應的篩選名單，繳管條件會自動展開。
- 繳管上方為「身分證字號／掃描結果」與「儲存繳管」。可輸入 12 碼條碼、預約編號或完整身分證字號，以 Enter 送出；登記成功後保留輸入焦點，不跳回頁首。姓名、條碼及成功／錯誤訊息出現在操作附近。
- 只接受「已領取」且未繳管的資料；重複登記、尚未領取、取消、退管、報廢及查無資料皆不更動紀錄。身分證對應多筆時，要求改用管件條碼。每次登記記錄台灣時間及原始狀態；10 分鐘內可復原，過期、已復原或已進入後續階段時鎖定。
- 本日紀錄在桌機使用表格，手機使用逐筆排列；待辦數字在手機縮短為名稱及數量，讓主要繳管操作更快出現。原本查詢、篩選、批次勾選、儲存及匯出收在「查詢與批次繳管」，繳管篩選亦接受條碼。批次操作會先確認整批資格，任一管件不符合時不會部分寫入。
- 輸入下方提供五組模擬情境：未繳管、已繳管、超過 10 分鐘、已接收、查無資料。繳管紀錄及復原紀錄會跟隨原有本機條碼名冊保存，匯出／匯入 DEMO 比對名冊亦會帶入；既有沒有繳管歷程的檔案仍可使用。
- 1440px、1024px、768px、390px、320px 共 126 項瀏覽器檢查通過，包括原文頁籤、數字同步、Enter 登記、輸入焦點與捲動位置、重複／錯誤、復原／超時、批次整批阻擋、條碼查詢、原有功能及重新整理保存（原圖表後續已移除），沒有水平溢出、執行錯誤或外部請求。19 項單元測試及建置通過；本次沒有新增套件或對外開放伺服器。

- 後台「腸篩管理 → 標籤列印」提供「預覽條碼」，以黑白長方形 Code 128 一維條碼呈現。每筆名單會隨機分配唯一 12 碼編號；重印、取消列印及狀態更新沿用同一條碼。標籤列印視窗包含院所、姓名、身分證、預約編號及條碼；CSV 增加條碼欄位。
- 點「掃描／比對條碼」進入 `/bowel-scan`，可即時相機掃描、拍照／選擇照片，或手動輸入 12 碼編號；辨識限定 Code 128。成功顯示個案、院所、發管及繳管狀態；查無、格式錯誤、相機權限拒絕或無法辨識都有提示。已取消的資料顯示禁止繼續發管／收管提示；掃描本身不更動作業狀態。
- 手機與電腦沒有後端同步：在電腦「匯出 DEMO 比對名冊」，將 JSON 檔案透過本地方式移至手機，再由掃描頁「匯入 DEMO 比對名冊」。匯入依預約編號更新或新增，會拒絕格式錯誤、重複條碼及超過 2 MB 的檔案；更新後狀態為匯出當時的快照，不是跨裝置即時資訊。
- 開發伺服器目前只綁定 `127.0.0.1`。要開放手機區網存取前，需先告知使用者再採用 `npm run dev -- --host 0.0.0.0`，手機以電腦的區網 IP 與實際埠號開啟 `/bowel-scan`。HTTP 區網網址的相機功能受瀏覽器限制，可用照片辨識或手動輸入；即時相機需要安全網址，且使用者明確允許相機。沒有部署至雲端或調整防火牆。
- 新增本地套件：`jsbarcode 3.12.3`、`@zxing/browser 0.1.5`、`@zxing/library 0.21.3`；間接相依 `@zxing/text-encoding 0.9.0`。ZXing 在啟動相機或照片辨識時才載入，首頁不下載辨識程式。下載前應說明用途及外部存取；不使用 CDN、遠端條碼圖片服務或上傳照片。
- 2026-10-02 執行 `npm audit --json` 回報整個前端 0 個已知漏洞，四個新增套件沒有 preinstall／install／postinstall 安裝腳本；這不是保證套件永遠無風險。套件來源：[JsBarcode 官方專案](https://github.com/lindell/JsBarcode)、[ZXing browser 官方專案](https://github.com/zxing-js/browser)。
- 13 項單元測試通過，包括隨機唯一性、條碼穩定、名冊格式與碰撞、原子匯入、查無及取消、localStorage 故障處理；桌機及 768px、390px、320px 瀏覽器驗證實際 Code 128 照片辨識、名冊匯入、列印／重印、取消列印、狀態保存及相機回復。不會將照片或比對名冊傳送到外部服務。

## 前台須知與基本資料測試

- 首頁僅呈現三個服務入口，點選「篩檢須知」後進入獨立頁面，再以四個篩選按鈕切換整合性篩檢、子宮頸抹片、乳房攝影與糞便潛血的準備、檢查與後續提醒；附官方來源及延伸閱讀。內容不套用 DEMO 年齡門檻，實際場次仍以院所通知為準。
- 首頁主要服務標題 24px、圖示 32px；預約主要操作至少 18px、56px 高，表單輸入 18px，維持正常字重。
- 無邀約碼選子宮頸抹片，輸入 `A200000012`：驗證通過後保留抹片，其他符合 DEMO 年齡、未做過且尚未預約的項目改為選填勾選，預設不加選。先選抹片場次，再選加選項目的場次與時段；同場次可提供檢查時會帶入場次，但不自動選時段。糞便潛血也可改選院所領管。`A200000021` 已做過、`A200000030` 年齡未到，仍不可通過。
- 加選沿用已驗證身分、基本資料與聯絡資料，一次核對所有項目的資格、時段及同場次總名額後，再分別建立預約；任何一項不符合時都不會寫入部分預約。完成頁列出各項目的場次、時段、地址與獨立編號。加選仍屬進度第 2 步，保留原本五步流程。
- 「查詢／取消預約」下方提供三組可一鍵帶入的測試資料：`A200000021 / 0911000021`（兩筆）、`A200000030 / 0911000030`（一筆）、`A200000049 / 0911000049`（查無資料）；查詢資料獨立於資格名冊。前兩組只在點「建立並帶入測試資料」時建立本機預約，不重複新增、不復原已取消的紀錄。剛完成的預約也會自動成為第四組測試資料。
- 查詢須產生並輸入畫面上的 DEMO 手機驗證碼；驗證後顯示所有未取消預約，可切換項目並個別取消，其他篩檢不受影響。取消最後一筆後回到查詢頁；修改身分證或手機會清除舊驗證碼。重新整理會重設所有本機測試資料。
- 本次加選與查詢流程於 1365px、768px、390px、320px 通過 93 項瀏覽器檢查，涵蓋原項目保留、預設不加選、同場次帶入、時段明確選擇、名額不足整批阻擋、完成前重新檢查、院所領管追蹤、資料沿用、多筆查詢及個別取消。未出現水平溢出或執行錯誤，7 項既有單元測試及 Vite 建置亦通過。
- 有邀約碼可使用 `3701000012`、`3702000021`，身分、姓名、出生日期與戶籍地址由模擬名冊帶入。
- 到基本資料步驟時，名冊欄位預設反灰。右上角「修改基本資料」可更正姓名與戶籍地址；取消會還原，儲存後重新鎖定，修改套用於此次預約。
- 身分證與出生日期保持唯讀，需更換時使用「重新驗證身分」，重新選場次及確認資格；換成另一人的資料會清除前一人的聯絡資料與現居地址。
- 「現居地址同戶籍地址」預設不勾選，現居地址保持可輸入，填寫完整才能完成。勾選時採用核對後的戶籍地址。
- 本機瀏覽器於 1365px、390px、320px 通過 181 項檢查，涵蓋須知切換、手機選單、其他項目提示、資料鎖定、修改／取消、地址必填、邀約／無邀約流程及資格錯誤。7 項既有資格與後台統計測試、Vite 建置皆通過。
