# Word 需求與本機 DEMO 對照

依據工作資料夾的「彰化縣衛生局癌症篩檢活動預約系統建置案系統功能需求」18 個章節核對。下表區分已可互動的前端流程與仍需完善的細節。

| 章節 | 已可操作的前端 DEMO | 尚未達到 Word 完整規格 |
|---|---|---|
| 1 整篩活動 | 年月、地區與項目查詢，場次建立、匯出、間隔時段與逐時段名額、公布確認。 | 民國日期表單輸入、村里連動選單、真實衛生所權限與簡訊排程。 |
| 2 衛生局所設站 | 場次、篩檢項目、合作院所、子抹車、乳攝院所、各篩檢項目分開的時段名額。 | 完整的分頁檢視／修改順序與真實院所名冊。 |
| 3 腸篩場次 | 院所清單篩選、新增院所、每週各日多時段與公休日曆。 | 鄉鎮與院所真實資料連動。 |
| 4 整篩民眾預約 | 邀約碼格式、場次、時段、手機及 E-mail 驗證、基本資料、完成、查詢取消。 | 真實邀約資格、名冊帶入、通知寄送。 |
| 5 設站民眾預約 | 資格確認、項目與鄉鎮／日期搜尋、時段、驗證、基本資料、再次預約其他項目與取消。 | 篩檢資格自動判斷與多項檢查在單筆預約內的整合。 |
| 6 腸篩民眾預約 | 資格確認、領管院所、電話驗證、基本資料、E-mail、完成與取消。 | 真實領管日曆、院所排班及名冊介接。 |
| 7–9 後台輸入預約 | 三類型表單；整篩／設站選時段，腸篩選衛生所或藥局；新增後反映名單。 | 真實身分資料帶入、完整跨鄉鎮權限與名額同步規則。 |
| 10–12 預約資料修改 | 身分證查詢、基本資料修改、換場次或腸篩院所、取消預約。 | 縣民／非縣民差異、縣市鄉鎮村里連動、設站多檢查項目逐項修改流程。 |
| 13–14 預約清冊 | 日期、鄉鎮、場次、篩檢項目與預約方式篩選；CSV 匯出。 | 真實角色資料範圍、`.xlsx` 匯出及完整報表欄位查核。 |
| 15 腸篩名單動態 | 狀態查詢、下一階段、10 分鐘內返回、退管與報廢示範。 | 逾期 7／14 日自動狀態與正式角色權限。 |
| 16 腸篩標籤列印 | 全選／單選、列印與取消列印、列印時間、瀏覽器標籤列印視窗、CSV。 | 實體標籤機格式與正式預約編號產生規則。 |
| 17 腸篩繳管 | 條件查詢、批次勾選、繳管狀態儲存與匯出。 | 相機 QR 掃描、跨來源資料整合與真實單位權限。 |
| 18 帳號申請 | 七個畫面、驗證碼時限、密碼規則、三次錯誤鎖定與重設示範。 | 憑證登入、真實簡訊／E-mail、戶政與醫事機構查核、伺服器端權限與密碼歷史。 |

## 使用限制

- 這是純前端 DEMO。資料保存在目前頁面的記憶體，重新整理後重設，也不會在不同裝置之間同步。
- 驗證碼顯示在本機畫面，不會寄送；資格與身分確認沒有介接外部服務。請勿輸入真實個資。
- 後台網址可直接開啟，帳號頁只示範登入流程，不構成正式存取管制。
- 表格匯出目前是 Excel 可開啟的 UTF-8 CSV，不是原生 `.xlsx`。
